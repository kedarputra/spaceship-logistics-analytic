# Architecture decision records

One file per decision: `NNNN-<slug>.md`, numbered from `0001`. Open questions and their recommendations are in `../decisions-open.md` (D1–D9); when one is decided, record it here and it wins over that file.

```markdown
# NNNN: <decision in a few words>

Status: accepted
Date: YYYY-MM-DD
Resolves: D<n> in docs/decisions-open.md

## Context
What forced the decision, with the facts that mattered.

## Decision
What was chosen.

## Consequences
What gets easier, what gets harder, what the README must mention.
```
